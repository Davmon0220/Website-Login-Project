
# Northline - Website Login Page

## Project Description

Northline is a responsive website login page created using HTML, CSS, and JavaScript. This project demonstrates how to build a modern and interactive login interface with form validation, dark and light mode, and user-friendly features.

The purpose of this project was to practice front-end web development and improve my skills in creating responsive and interactive websites.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

### Login Form
- Email address input
- Password input
- Sign-in button
- Keep me signed in checkbox
- Forgot password link
- Create account link

### Form Validation
- Checks for empty input fields
- Validates email address format
- Requires a password of at least 8 characters
- Displays error messages for invalid information
- Displays success messages when validation passes

### Password Visibility
- Show and hide password button
- JavaScript functionality to toggle password visibility

### Dark and Light Mode
- Switch between dark and light themes
- Saves theme preferences using localStorage
- Detects the user's preferred browser theme

### Responsive Design
- CSS Grid layout
- Mobile-friendly design
- Hover effects and smooth transitions
- Modern buttons and input fields
- Responsive login card

## File Descriptions

### index.html
Contains the structure of the login page, including the email and password fields, buttons, navigation links, and branding section.

### styles.css
Controls the website's appearance, including colors, fonts, spacing, layout, responsive design, and dark mode styling.

### app.js
Contains the JavaScript functionality for form validation, password visibility, theme switching, and user feedback messages.

### README.md
Contains the project documentation and instructions.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open `index.html` in your web browser.
5. Test the login form and interactive features.

No additional installation is required.
